1. The Problem: Zero-Drift Consistency at Live Scale

FTPON's second half is 38 weekly iterations revisiting the same pivotal night. Hundreds of modular AI-generated scenes must hold character identity, lighting logic, and world continuity while re-rendering under live sports-data triggers within seconds. Offline consistency is solved; consistency at live scale is the open problem.

2. The Trigger State Matrix (TSM)

Live sports are unpredictable. We do not key modules to timestamps; we key them to (Location × Emotional State).

The Higgsfield Mandate: We need to batch-generate ~26 core modules per episode under a single character lock. If Higgsfield can pass the zero-drift batch test, the entire 38-week production model is validated.

3. The BOYD Live-Ops & Autonomous Generation Architecture

FTPON is a live software system. The BOYD backend is architected to ingest Sportradar webhooks, evaluate the Trigger State Matrix (TSM), and command OBS/Telegram in under 15 seconds. Higgsfield's stack provides the visual engine for this pipeline.

BOYD (The Live Showrunner): The n8n orchestration layer. Reads live sports data, maps it to the TSM (Reactive, Oral, Sacred, Judgment blocks), and fires WebSocket commands to OBS.

Higgsfield Genjutsu (The Zero-Drift Engine): The core visual mandate. BOYD requests batch generations of the 26 modular scene library. Genjutsu ensures the 5 principal characters and lighting logic hold absolute identity across every A/B variant and reaction insert.

MiniMax H3 Max (The Live Trigger Engine): Routed via fal.ai. When a live goal requires a net-new atmospheric plate or rapid character reaction variant within the 15-second broadcast window, BOYD routes to H3 Max for sub-30-second generation.

GPT Astra (The 3D & Finishing Operator): Astra autonomously operates Blender for 3D set extensions and DaVinci Resolve for automated conform and grading of the AI-generated modules before they are vaulted.

Higgsfield Supercomputer (The Cinematic Planner): For complex multi-shot spine scenes, BOYD feeds the screenplay to the Supercomputer to autonomously plan, pick models, and render with Genjutsu consistency locks.

4. The Three-Tier Infrastructure

Tier 1: Local Sovereign Compute (Air-Gapped)
Puget/ProArt stack. Reserved for the FF-4 Restricted Vault (the season finale convergence shots) and master LoRA training. The most sensitive narrative spoilers never touch a third-party server.
Tier 2: Partner Inference (Higgsfield + fal.ai)
High-volume, consistency-locked generation for the weekly 26-module library via Higgsfield MCP/API. High-speed atmospheric generation via MiniMax H3 Max (fal.ai). Character reaction beats and glass-layer assets.
Tier 3: Agentic Orchestration (BOYD + GPT Astra)
BOYD dynamically routes tasks based on IP sensitivity, latency, and credit availability. GPT Astra executes traditional software operations (Blender, Unreal, DaVinci) as BOYD's technical agent. Cloud overflow (Together/Replicate) for batch upscaling.
